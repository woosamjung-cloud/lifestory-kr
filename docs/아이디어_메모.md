# 아이디어 메모 (나중에 진행)

## 해외 결제: 페이팔 인보이스
- 사장님 페이팔 계정으로 메일 인보이스를 보내는 방식
- 1단계(수동): 상점에서 "청구서 요청" 접수 → 운영자가 페이팔에서 인보이스 발송 → 결제 확인 후 현황판에서 지급
- 2단계(자동): 페이팔 인보이스 API로 로그인 이메일에 자동 발송, 결제 알림(웹훅)으로 바로 지급
- 확인: 판매용은 페이팔 비즈니스 계정 권장

## 새 행선지: 광화문 기도 광장
- 해돋이·노을처럼 함께 모여 마음을 비는 곳
- 특정 종교·정치 구호 없이, 누구나 자기 방식으로 기도하고 소망하는 광장으로
- 촛불, 기도 풍등, 조용한 묵념처럼 말없이 함께하는 활동 위주
- 자유 글은 걸러내고 정해진 문구 위주

## 그 밖에 남은 것
- 가까이 온 사람과 하트·호감도·정해진 문구로 둘만의 속삭임 (자유 1:1 채팅은 하지 않음)
- 수노 AI로 사이트 곡 만들기 → 배경음악 → 음원 유통 (가사·수노 입력 문구 준비)
- 도메인 연결 (예: chuunikka.com), 카카오 로그인·카카오 공유
- 실제 결제 전: Render 유료 플랜 + 영구 디스크, 메일 서비스 키, 키움페이 연동
