# 별점 · 건의하기

- 위치: 더보기 → ⭐ 별점 · 건의하기 (별 1~5개 + 500자까지 자유 글)
- 저장: 서버 `data/feedback.jsonl` (한 줄에 하나: 시각, 별점, 글, 장소, 언어, 기기 번호 앞 8자리)
- 공개 통계 `/api/stats` 에는 **개수와 평균 별점만** 나옴 (글 내용은 안 나옴)
- 글 보기 (운영자만):
  1. Render → Environment 에 `ADMIN_KEY` 를 8자 이상 아무 비밀 문구로 추가
  2. 브라우저에서 `https://bangguseok-haedoti.onrender.com/api/feedback?key=그문구` → 최근 200개
- 남용 방지: 같은 기기 1분에 한 번, 같은 IP 하루 10번
- 주의: 무료 서버는 다시 배포하면 파일이 지워질 수 있음 → 영구 디스크를 붙이기 전에는 가끔 내려받아 두기
