# 간편 로그인 설정 (구글 · 카카오 · 네이버)

키를 넣은 곳만 로그인 창에 버튼이 나타납니다. 받는 정보는 **별명과 이메일**뿐입니다.
모든 키는 채팅에 붙여 넣지 말고 **Render → 서비스 → Environment** 에 넣어 주세요.

콜백(Redirect) 주소는 사이트 주소 뒤에 붙입니다. (도메인을 바꾸면 각 콘솔에도 새 주소를 추가)
- `https://bangguseok-haedoti.onrender.com/auth/kakao/callback`
- `https://bangguseok-haedoti.onrender.com/auth/google/callback`
- `https://bangguseok-haedoti.onrender.com/auth/naver/callback`

## 카카오 (developers.kakao.com)
1. 내 애플리케이션 → 애플리케이션 추가
2. 앱 키의 **REST API 키** → Render `KAKAO_REST_KEY`
3. 카카오 로그인 활성화, Redirect URI에 위 카카오 주소 등록, 플랫폼 Web에 사이트 주소 등록
4. 동의항목: 닉네임(필수), 카카오계정(이메일)(선택 — 이메일은 비즈 앱 전환 후 받을 수 있음, 없으면 카카오 번호로 계정을 구분)
5. (선택) 보안 → Client Secret 사용 시 `KAKAO_SECRET`

## 구글 (console.cloud.google.com)
1. API 및 서비스 → OAuth 동의 화면 (외부, 앱 이름 "이불 밖은 추우니까")
2. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션, 승인된 리디렉션 URI에 위 구글 주소
3. 클라이언트 ID → `GOOGLE_CLIENT_ID`, 보안 비밀 → `GOOGLE_CLIENT_SECRET`

## 네이버 (developers.naver.com)
1. Application 등록 → 사용 API: 네이버 로그인, 제공 정보: 별명·이메일
2. 서비스 URL에 사이트 주소, Callback URL에 위 네이버 주소
3. Client ID → `NAVER_CLIENT_ID`, Client Secret → `NAVER_CLIENT_SECRET`

## 그 밖에
- 도메인을 연결하면 `PUBLIC_URL`에 새 주소를 넣고, 각 콘솔의 콜백 주소도 새 주소로 추가해 주세요.
- 이메일 로그인 링크(Resend)는 소셜 로그인이 없는 사람을 위한 대안으로 그대로 남아 있습니다.
