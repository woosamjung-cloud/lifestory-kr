# 나라·행선지·언어 늘리는 방법

## 1. 언어 추가 (예: 일본어)
1. `public/js/lang/en.js`를 복사해 `public/js/lang/ja.js`를 만듭니다.
   - `code: 'ja'`, `label: '日本語'`
   - `keys`: 첫 화면 문장 (키로 찾는 문장)
   - `text`: 화면에 나오는 한국어 문장 → 일본어
   - `patterns`: 숫자가 들어가는 문장 (예: "3분 전")
2. `public/js/lang/index.js`에 한 줄 추가합니다: `import ja from './ja.js';` 후 `PACKS = [ko, en, ja]`
3. 끝. 첫 화면의 언어 버튼이 자동으로 생기고, 일본어 기기에서는 처음부터 일본어로 열립니다.

화면의 원래 글자는 한국어입니다. 번역이 없는 문장은 한국어로 그대로 보이니, 새 문장을 만들면 각 언어 파일의 `text`에 한 줄씩 넣어 주세요.

## 2. 나라 추가 (예: 일본)
`public/js/countries.js`의 `COUNTRIES`에 한 줄:
```js
JP: { flag: '🇯🇵', code: 'JAPAN', names: { ko: '일본', en: 'Japan', ja: '日本' }, weather: 'openmeteo' },
```
- `weather`: 그 나라 날씨를 가져올 곳. `weather.js`의 `PROVIDERS`에 같은 이름의 제공처를 추가합니다.
  - 지금은 한국 기상청(`kma`)만 있습니다. 해외는 무료·키 없는 Open-Meteo 같은 곳을 붙이면 됩니다.
  - 제공처는 `{ sky, pty, temp, wind, label }` 모양으로 돌려주면 하늘·구름·비·바람이 그대로 연동됩니다.

## 3. 행선지(장소) 추가 (예: 후지산 해돋이)
1. `public/js/sun.js`의 `PLACES`에 장소를 추가합니다.
   - `key`, `country: 'JP'`, `name`(한국어), `names: { en: 'Mt. Fuji', ja: '富士山' }`
   - `lat`, `lon`, `tz`(시간대, 예: 'Asia/Tokyo'), `kind: 'sunrise'` 또는 `'sunset'`
2. `public/js/countries.js`의 `DESTINATIONS`에 그 `key`를 넣습니다.
3. 끝. 매표소에 그 나라 국기와 함께 승차권이 한 장 생기고, 실제 일출·일몰 시각과 날씨가 맞춰집니다.
   - 장소마다 다른 풍경(산, 사원 등)을 원하면 장면 그림(`scene.js`)에 풍경을 추가해야 합니다.

## 4. 글꼴
- 한국어 손글씨: 신영복체 → KOTRA 송글씨 → 나눔붓글씨 순서로 대체 (`style.css`의 `--title`)
- 영어 손글씨: `style.css` 맨 아래 주석에 자리가 있습니다. 상업적 이용 허락을 받은 글꼴만 넣어 주세요.
