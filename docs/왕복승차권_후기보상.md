# 왕복 승차권 · 귀가 인증 후기 보상

## 구도
- 승차권은 **편도·왕복 둘 다 무료**. 기본 선택은 왕복.
- 왕복으로 다녀와서 더보기 → **🏠 집으로 돌아가기** → 귀가 열차 → **귀가 인증 사진**
  (장소·날짜·머문 시간·와! 횟수·띄운 소원/편지)
- 사진과 한 줄 후기를 SNS에 올리고 그 글 주소를 붙여 넣으면 **소원 동전 10개(1,000원어치)**.
- 편도로 탄 사람에게는 "다음엔 왕복으로 타 보세요" 안내만.

## 부정 방지 (server.js `reviewReward`)
- 왕복 승차권으로 탄 기록이 있어야 함
- 실제로 자리에 앉아 있던 시간 10분 이상 (서버가 직접 잼, `REVIEW_MIN_SEC`)
- SNS 글 주소만: 인스타그램·스레드·X·페이스북·네이버 블로그/카페/포스트·틱톡·유튜브·브런치·카카오스토리·밴드·티스토리·velog
- 프로필 주소(경로가 짧은 주소)는 안 됨, 같은 글 주소는 한 번만
- 같은 기기 하루 한 번(20시간), 같은 IP 하루 3번
- 받은 후기 주소는 `shop.json`의 `reviews`에 남음 → 운영자가 나중에 확인 가능

## 법적 표시 (중요)
대가(소원 동전)를 받는 후기는 「추천·보증 등에 관한 표시·광고 심사지침」에 따라 **대가를 받았다는 사실을 밝혀야** 합니다.
- 공유 문구에 `#소원동전후기 (소원 동전을 받고 남기는 후기예요)`가 자동으로 들어감
- 받기 칸 아래에도 안내 문구 표시
- 사용자가 문구를 지우고 올리는 것까지 막을 수는 없으므로, 확인 시 문구가 없는 후기는 보상 회수·안내를 검토

## 한계
- SNS 글 내용을 자동으로 확인하지는 않음(로그인 필요한 SNS가 많음). 주소 형식·머문 시간·횟수 제한으로 남용을 줄이고, 기록된 주소를 운영자가 가끔 확인하는 방식.
- 머문 시간·왕복 기록은 서버 메모리에만 있어 서버가 다시 켜지면 그날 기록이 초기화됨.
