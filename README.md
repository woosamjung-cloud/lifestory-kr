# 🌅 방구석 해돋이호

> 이불 밖은 추우니까, 방에서 같이 보는 해돋이

잠옷 입은 동물 캐릭터로 **온라인 열차**에 타서, **정동진 해돋이**와 **정서진 해넘이**를 **실제 일출·일몰 시각에 맞춰** 여러 사람과 함께 보는 웹 서비스입니다.
온라인 절 '산사'의 성공 공식(설치·가입 없이 링크 하나, 귀여운 캐릭터, 말없이 함께 있는 느낌, 작은 의식 행동)을 해돋이·해넘이 주제에 맞게 다시 설계했습니다.

- 기획안: [`docs/방구석해돋이호_기획안.docx`](docs/방구석해돋이호_기획안.docx)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🕐 실시간 하늘 | 천문 공식으로 해의 고도·방위각을 계산해 밤 → 여명 → 해돋이 → 낮 하늘이 실제 시각대로 바뀝니다. 외부 API가 필요 없습니다. |
| 🚂 자동 안내 | 접속 시각에 맞춰 가장 가까운 **정동진 해돋이** 또는 **정서진 해넘이**로 데려갑니다. |
| 🎫 승차권 | 이름·캐릭터·담요 색을 고르면 실제 좌석 번호가 적힌 승차권 이미지(4:5)를 만들어 저장·공유합니다. |
| 👥 함께 보기 | 같은 해변에 앉은 다른 승객이 보이고, "함께 보는 중 N명"이 실시간으로 표시됩니다. 채팅은 없습니다. |
| 🚉 만석·대기 | 좌석 수를 넘으면 대기 순번을 받고, 자리가 나면 자동으로 앉습니다. |
| 🙌 와! | 함성을 누르면 내 캐릭터가 만세를 하고 다른 승객 화면에도 보입니다. 이벤트별로 누적됩니다. |
| 🏮 / ⛵ | 정동진에서는 소원 풍등, 정서진에서는 종이배를 띄웁니다. **적은 글은 서버로 보내지 않습니다.** |
| 🎉 그 순간 | 해가 수평선을 넘는 순간 축하 연출과 알림이 나옵니다. |
| 📸 인증 카드 | 지금 하늘을 배경으로 "함께 봤어요" 카드와 함께 본 사람 수, 소원을 담아 저장·공유합니다. |
| ⏩ 미리보기 | 해돋이·해넘이 시간이 아닐 때 그 장면을 60초로 빠르게 볼 수 있습니다. |
| ✨ 특별 이벤트 | 12월 31일 정서진 **마지막 해넘이**, 1월 1일 정동진 **새해 첫 해돋이**는 자동으로 특별 표시됩니다. |

## 내 컴퓨터에서 실행하기

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
```

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

### 원하는 시각으로 시험해 보기

주소 뒤에 `?t=시각`을 붙이면 그 시각부터 시계가 흐릅니다.

- 새해 첫 해돋이 직전: `http://localhost:3000/?t=2027-01-01T07:37:00%2B09:00`
- 올해 마지막 해넘이 직전: `http://localhost:3000/?t=2026-12-31T17:20:00%2B09:00`

### 테스트

```bash
npm test
```

## 인터넷에 올리기 (배포)

### 방법 1. Render (추천 · 함께 보기 기능 포함)

1. [render.com](https://render.com)에 GitHub 계정으로 가입합니다.
2. **New → Blueprint**를 누르고 이 저장소를 고릅니다. (`render.yaml`을 읽어 자동 설정됩니다)
3. 몇 분 뒤 `https://bangguseok-haedoti.onrender.com` 같은 주소가 생깁니다.

> 무료 요금제는 15분 동안 접속이 없으면 잠들었다가 첫 접속 때 깨어나느라 30초쯤 걸리고, 다시 시작하면 함성 수 같은 누적 기록이 초기화됩니다.
> **1월 1일 같은 큰 이벤트 전에는 유료 요금제(Starter 이상)로 올려 두는 것을 권합니다.**

### 방법 2. GitHub Pages / Netlify / Vercel (화면만 · 혼자 보기)

`public/` 폴더만 올리면 서버 없이도 동작합니다. 이 경우 하늘·승차권·풍등·인증 카드는 모두 되지만 **다른 승객과 함께 보기는 꺼집니다**("혼자 보기" 모드).
화면은 이렇게 올리고 서버만 Render에 따로 두려면 `public/config.js`에 서버 주소를 적으세요.

```js
window.HAEDOTI_CONFIG = { server: 'https://bangguseok-haedoti.onrender.com' };
```

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 서버 포트 |
| `SEATS` | 500 | 장소(정동진·정서진)마다 좌석 수. 넘으면 대기열 |
| `MAX_CLIENTS` | 20000 | 서버 전체 동시 접속 상한 |
| `DATA_DIR` | `./data` | 함성 수·함께 본 사람 수 저장 위치 |

## 개인정보와 안전

- 회원가입이 없고, 이름은 **내 승차권 이미지에만** 쓰이며 다른 승객에게 보이지 않습니다.
- 풍등·종이배에 적은 글은 서버로 보내지 않습니다. 다른 승객에게는 불빛과 배 모양만 보입니다.
- 채팅이 없어서 욕설·도배 관리 부담이 없습니다.
- 서버는 기기마다 만든 무작위 번호만으로 "함께 본 사람" 수를 셉니다.

## 참고

- 일출·일몰 시각은 NOAA 천문 공식으로 계산하며, 지형과 고도에 따라 실제와 1~2분 차이가 날 수 있습니다.
- 정동진·정서진은 지명만 사용하며, 지자체 로고·축제 명칭·실제 철도회사 상표는 쓰지 않습니다.
