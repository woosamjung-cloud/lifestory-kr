# 🌅 방구석 해돋이호

> 이불 밖은 추우니까, 방에서 같이 보는 해돋이

담요를 두른 자기 모습(어른 감성 일러스트)으로 **온라인 해돋이 특별열차**에 타서, **정동진 해돋이**와 **정서진 해넘이**를 **실제 일출·일몰 시각에 맞춰** 여러 사람과 함께 보는 웹 서비스입니다.
온라인 절 '산사'의 성공 공식(설치·가입 없이 링크 하나, 귀여운 캐릭터, 말없이 함께 있는 느낌, 작은 의식 행동)을 해돋이·해넘이 주제에 맞게 다시 설계했습니다.

- 서비스 주소: https://bangguseok-haedoti.onrender.com
- 현황판(방문·승차권·인증 카드·동시 접속): https://bangguseok-haedoti.onrender.com/stats.html
- 기획안: [`docs/방구석해돋이호_기획안.docx`](docs/방구석해돋이호_기획안.docx)
- 홍보 계획(게시물 문구·보도자료 포함): [`docs/방구석해돋이호_홍보계획.docx`](docs/방구석해돋이호_홍보계획.docx)
- 홍보 영상(세로 1080×1920, 32초, 시연 화면): [`promo/haedoti_reels_1080x1920.mp4`](promo/haedoti_reels_1080x1920.mp4)

## 주요 기능

| 기능 | 설명 |
|---|---|
| 🕐 실시간 하늘 | 천문 공식으로 해의 고도·방위각을 계산해 밤 → 여명 → 해돋이 → 낮 하늘이 실제 시각대로 바뀝니다. 외부 API가 필요 없습니다. |
| 🚂 자동 안내 | 접속 시각에 맞춰 가장 가까운 **정동진 해돋이** 또는 **정서진 해넘이**로 데려갑니다. |
| 🎫 승차권 | 이름·캐릭터·담요 색을 고르면 실제 좌석 번호가 적힌 승차권 이미지(4:5)를 만들어 저장·공유합니다. |
| 👥 함께 보기 | 같은 해변에 앉은 다른 승객이 보이고, "함께 보는 중 N명"이 실시간으로 표시됩니다. 채팅은 없습니다. |
| 🚉 만석·대기 | 좌석 수를 넘으면 대기 순번을 받고, 자리가 나면 자동으로 앉습니다. |
| 🙌 와! | 함성을 누르면 내 캐릭터가 만세를 하고 다른 승객 화면에도 보입니다. 이벤트별로 누적됩니다. |
| 🏮 / ⛵ | 정동진에서는 소원 풍등, 정서진에서는 종이배를 띄웁니다. **적은 글은 서버로 보내지 않습니다.** |
| 🎉 그 순간 | 해가 수평선을 넘는 순간 축하 연출과 알림이 나옵니다. |
| 📸 인증 카드 | 지금 하늘을 배경으로 "함께 봤어요" 카드와 함께 본 사람 수, 소원을 담아 저장·공유합니다. |
| ⏩ 미리보기 | 해돋이·해넘이 시간이 아닐 때 그 장면을 60초로 빠르게 볼 수 있습니다. |
| ✨ 특별 이벤트 | 12/24 **크리스마스 이브 해넘이**, 12/25 **크리스마스 아침 해돋이**, 12/31 정서진 **마지막 해넘이**, 1/1 정동진 **새해 첫 해돋이**를 자동으로 특별 표시합니다. |
| 🌌 실제 밤하늘 | 밝은 별 1,289개와 별자리 88개를 실제 위치·밝기·색으로 그리고, 달의 실제 위치와 위상을 계산합니다. 보름달이 뜨면 하늘이 밝아져 어두운 별이 덜 보입니다. |
| ☄️ 유성우 | 사분의자리(1/4)·페르세우스(8/13)·쌍둥이자리(12/14) 등 8대 유성우의 극대일과 복사점에 맞춰 유성이 떨어집니다 (실제 시간당 유성 수의 3배로 연출). |
| 🌦️ 실제 날씨 | 기상청 초단기예보로 정동진·정서진의 구름량, 비·눈, 기온을 반영합니다 (`KMA_API_KEY` 필요). 시험: `?wx=4,3,-2` |
| 🔥 불멍 | 정동진은 돌을 둘러 쌓은 모닥불, 정서진은 무쇠 화로. 불꽃이 일렁이고 불티가 오르며 밤에는 주변을 따뜻하게 비춥니다. |
| 🔊 배경음 | 파도·바람·모닥불 타닥 소리를 브라우저에서 직접 합성 (음원 파일 없음). 탑승할 때 켜지고 오른쪽 위에서 끌 수 있으며, 기상청 풍속에 따라 바람 소리가 달라집니다. |
| 🎁 상점 | 30일 이용권 아이템(촛불 1,000원·후레쉬 1,000원·폭죽 2,000원·큰 캠프파이어 2,900원·연말 패키지 4,900원)과 소원 동전(1,000원=11개). 회원가입 없이 기기별 저장 + 복구 코드 |
| 🪙 동전 소원 | 동전 1개를 바다에 던지면 고른 소원 문구(10가지)가 모든 사람 하늘에 떠오름. 자유 글이 아니라 욕설·개인정보 걱정 없음 |
| 🔗 공유 미리보기 | 카카오톡·인스타·페이스북에 링크를 붙이면 미리보기 이미지(`og.png`)가 나옵니다. |
| 📱 홈 화면 추가 | 휴대폰 홈 화면에 앱처럼 추가할 수 있습니다(PWA). |

## 내 컴퓨터에서 실행하기

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
```

```bash
npm start
```

브라우저에서 http://localhost:3000 을 엽니다.

### 원하는 시각으로 시험해 보기

주소 뒤에 `?t=시각`을 붙이면 그 시각부터 시계가 흐릅니다.

- 새해 첫 해돋이 직전: `http://localhost:3000/?t=2027-01-01T07:37:00%2B09:00`
- 올해 마지막 해넘이 직전: `http://localhost:3000/?t=2026-12-31T17:20:00%2B09:00`
- 타임랩스(60배속): 주소 끝에 `&speed=60`을 붙입니다.

### 테스트

```bash
npm test
```

계산 테스트(일출·일몰, 특별 이벤트)와 서버 테스트(좌석·대기열·함성·접속 제한·보안)가 함께 돌아갑니다.

### 부하 시험 (동시 접속)

서버를 IP 제한 없이 켠 다음, 다른 터미널에서 가상 승객을 접속시킵니다.

```bash
MAX_PER_IP=100000 npm start
```

```bash
node test/load.mjs 10000 20
```

개발 환경 시험 결과 (4코어, 서버 1대):

| 동시 접속 | 접속 완료 | 함성 전달 지연(95%) | 서버 CPU | 접속당 데이터 |
|---|---|---|---|---|
| 3,000명 | 1.2초 | 0.10초 | 약 20% | 초당 0.27KB |
| 10,000명 | 2.1초 | 0.18초 | 약 31% | 초당 0.11KB |

> 같은 컴퓨터 안에서 잰 값이라 실제 인터넷에서는 지연이 더 늘어납니다. 1월 1일 전에 배포한 서버로 다시 시험하세요.

## 인터넷에 올리기 (배포)

### 방법 1. Render (추천 · 함께 보기 기능 포함)

1. [render.com](https://render.com)에 GitHub 계정으로 가입합니다.
2. **New → Blueprint**를 누르고 이 저장소를 고릅니다. (`render.yaml`을 읽어 자동 설정됩니다)
3. 몇 분 뒤 `https://bangguseok-haedoti.onrender.com` 같은 주소가 생깁니다.

> 무료 요금제는 15분 동안 접속이 없으면 잠들었다가 첫 접속 때 깨어나느라 30초쯤 걸리고, 다시 시작하면 함성 수 같은 누적 기록이 초기화됩니다.
> **1월 1일 같은 큰 이벤트 전에는 유료 요금제(Starter 이상)로 올려 두는 것을 권합니다.**

### 방법 2. GitHub Pages / Netlify / Vercel (화면만 · 혼자 보기)

GitHub Pages는 설정이 들어 있습니다(`.github/workflows/pages.yml`). 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꾸면 `main` 브랜치에 올릴 때마다 자동으로 배포됩니다.


`public/` 폴더만 올리면 서버 없이도 동작합니다. 이 경우 하늘·승차권·풍등·인증 카드는 모두 되지만 **다른 승객과 함께 보기는 꺼집니다**("혼자 보기" 모드).
화면은 이렇게 올리고 서버만 Render에 따로 두려면 `public/config.js`에 서버 주소를 적으세요.

```js
window.HAEDOTI_CONFIG = { server: 'https://bangguseok-haedoti.onrender.com' };
```

## 설정 (환경 변수)

| 이름 | 기본값 | 설명 |
|---|---|---|
| `PORT` | 3000 | 서버 포트 |
| `SEATS` | 1000 | 장소(정동진·정서진)마다 좌석 수. 넘으면 대기열. 1월 1일에는 5000 이상 권장 (화면에는 앞쪽 150석만 그려서 늘려도 가벼움) |
| `MAX_CLIENTS` | 20000 | 서버 전체 동시 접속 상한 |
| `MAX_PER_IP` | 30 | 한 IP에서의 동시 접속 상한 (도배 방지) |
| `KMA_API_KEY` | (없음) | 공공데이터포털 「기상청_단기예보 조회서비스」 일반 인증키(Decoding). 없으면 날씨 없이 동작 |
| `SHOP_MODE` | test | `off` 상점 숨김 / `test` 테스트 결제(돈 안 나감) / `live` 실제 결제 |
| `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY` | (없음) | 토스페이먼츠 키. `live`에 필요. 비밀 키는 절대 화면·저장소에 넣지 말 것 |
| `DATA_DIR` | `./data` | 함성 수·함께 본 사람 수 저장 위치 |

## 통계와 현황판

`/stats.html`에서 동시 접속, 장소별 착석·대기, 오늘·누적 방문 기기 수, 승차권·인증 카드·저장 수, 와! 함성, 풍등·종이배 수를 10초마다 보여줍니다. 원본 숫자는 `/api/stats`에서 볼 수 있습니다.
외부 분석 서비스를 쓰지 않고 숫자만 셉니다. 무료 요금제에서는 서버가 다시 시작되면 기록이 초기화됩니다.

## 유료 판매 시작 전 체크리스트

1. 토스페이먼츠 가입·계약 → 클라이언트 키와 시크릿 키를 Render 환경 변수에 입력
2. **Render Disk(영구 저장소)를 붙이고 `DATA_DIR`를 그 경로로** (안 하면 재배포 때 구매 기록이 사라짐)
3. `public/terms.html`, `refund.html`, `privacy.html`의 [ ] 부분(상호·사업자번호·통신판매업 신고번호·연락처) 채우기
4. `SHOP_MODE=live`로 바꾸고 소액으로 실제 결제·환불을 한 번씩 시험

## 개인정보와 안전

- 회원가입이 없고, 이름은 **내 승차권 이미지에만** 쓰이며 다른 승객에게 보이지 않습니다.
- 풍등·종이배에 적은 글은 서버로 보내지 않습니다. 다른 승객에게는 불빛과 배 모양만 보입니다.
- 채팅이 없어서 욕설·도배 관리 부담이 없습니다.
- 서버는 기기마다 만든 무작위 번호만으로 "함께 본 사람" 수를 셉니다.

## 참고

- 일출·일몰 시각은 NOAA 천문 공식으로 계산하며, 지형과 고도에 따라 실제와 1~2분 차이가 날 수 있습니다.
- 정동진·정서진은 지명만 사용하며, 지자체 로고·축제 명칭·실제 철도회사 상표는 쓰지 않습니다.
